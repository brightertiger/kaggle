# Portfolio Website

This directory contains the interactive portfolio website showcasing the Kaggle competition solutions.

## 🚀 Live Website

The website is automatically deployed using GitHub Actions and is available at:
**https://brightertiger.github.io/kaggle/**

## 📁 Files

- `index.html` - Main HTML file
- `styles.css` - CSS styling and responsive design
- `script.js` - JavaScript for interactivity
- `package.json` - Project configuration
- `.github/workflows/deploy.yml` - GitHub Actions deployment workflow

## 🛠️ Features

- **Responsive Design**: Works on desktop, tablet, and mobile
- **Interactive Filtering**: Filter projects by category
- **Smooth Animations**: CSS and JavaScript animations
- **Modern UI**: Clean, professional design
- **Fast Loading**: Optimized for performance
- **Accessibility**: Keyboard navigation and screen reader support

## 🔧 Local Development

To run the website locally:

```bash
# Using Python (recommended)
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.

## 📱 Mobile Optimization

The website is fully responsive and optimized for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)

## 🎨 Customization

To customize the website:

1. **Colors**: Update CSS variables in `styles.css`
2. **Content**: Modify the HTML in `index.html`
3. **Interactions**: Update JavaScript in `script.js`
4. **Projects**: Add/remove project cards in the HTML

## 🚀 Deployment

The website is automatically deployed using GitHub Actions:

1. Push changes to the `main` or `master` branch
2. GitHub Actions automatically builds and deploys
3. Website is available at the GitHub Pages URL
