## Repository structure

The portfolio has 20 competition folders. Each uses `main.py` as its CLI entry point,
`src/` for pipeline code, and `README.md` for the solution write-up. The shared folder
layout also includes `dry_run.py` to exercise the pipeline on a small synthetic sample.
Dry-run scripts are being added; check that the selected folder has one before running it.
Dependencies and command-line options are specific to each competition.

The root `index.html`, `styles.css`, and `script.js` form the portfolio home.
`build_site.py` renders every competition README to an ignored `<competition>/index.html`
in CI. See [the website guide](./WEBSITE_README.md) for the build and preview workflow.

## Running a dry run

From a competition folder, install its dependencies and run its synthetic smoke test:

```bash
cd jigsaw
python -m pip install -r requirements.txt
python dry_run.py
```

A dry run exercises the pipeline on generated sample data rather than the full Kaggle
dataset. It checks basic execution, not leaderboard performance. Consult the folder's
README and `dry_run.py` for supported options, dependencies, and output locations.
